- fresh persistent enrollment through production iOS Keychain/Keybay;

- stable node ID and Tailscale IPv4 address were preserved;

- a content-free inventory classified all nine package-owned entries and
  rejected unknown artifacts or unsafe modes; and

### Hosted mobile boundaries

Temporary receipt instrumentation also established this partial publication
evidence:

- `tls.bind` returned the package's expected upstream-conformant mobile error;
- a Serve mapping was replaced by Funnel on the same 443/path coordinate;
- closing the stale Serve handle did not clear the replacement Funnel mapping;
- an independent host fetched the iPhone's public Funnel URL with HTTP 200 and
  the exact expected body `physical-ios-publication-ok`.

All hosted test nodes were deleted. Interrupted local receipt namespaces were
explicitly reset; the cleanup entrypoint reported success, and a final API
query found no remaining `dune-smoke-ios` or `dune-ios-pub-*` nodes.

## Not qualified by this receipt

- Fresh HTTPS Serve could not complete because Tailscale's certificate path
  repeatedly returned `SetDNS ... 500 Internal Server Error, failed to create
  DNS record`; aggressive retries eventually received HTTP 429. This matches
  the pre-existing external ACME issuance note in the rearchitecture plan.
- Therefore the complete Serve -> Funnel -> replacement Serve HTTPS handshake
  is still unproven on iOS. Keep mobile Serve/Funnel marked unqualified.
- No Android physical-device evidence was collected.

The ordinary smoke pass and production-custody pass are device evidence. The
hosted result is deliberately partial and must not be reported as full mobile
Serve/Funnel qualification.
